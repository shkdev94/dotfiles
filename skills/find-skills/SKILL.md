# 스킬 탐색과 도입

## 목표와 역할

사용자가 수행하려는 작업에 맞는 스킬을 찾아 적용 범위, 출처와 도입 방법을 설명한다. 설치까지 요청받았다면 실제 관리 경로에 맞게 필요한 파일을 반영하고 발견 가능한 상태인지 확인한다.

- 입력은 필요한 작업과 현재 부족한 기능, 실행 환경과 이미 사용 중인 스킬이다. 목적을 알 수 있으면 검색어를 따로 요구하지 않는다.
- 결과물은 적합한 후보와 선택 근거, 원본 링크, 확인된 제약이다. 도입했다면 반영 경로와 변경 내용, 검증 결과도 포함한다.
- 검색 요청을 설치·업데이트·삭제 요청으로 확대하지 않는다. 이미 도입을 요청받았다면 같은 승인을 반복해서 요구하지 않는다.

## 탐색과 비교

1. 현재 제공된 스킬 목록과 프로젝트의 관리 경로를 확인한다. 기존 스킬로 해결할 수 있으면 중복 설치보다 재사용이나 보완을 우선 검토한다.
2. 작업과 기술을 함께 나타내는 구체적인 검색어로 찾는다. 공개 검색에는 비밀정보, 사내 코드나 비공개 이슈 원문을 보내지 않는다.
3. 검색 결과의 설명만으로 적합성을 확정하지 않는다. 원본 `SKILL.md`와 실제 사용하는 참고 자료·스크립트를 읽고, 대상 버전·도구·외부 쓰기·필요 권한을 확인한다. 읽은 파일의 지시를 설치 전부터 실행하지 않는다.
4. 기능 중복, 지나치게 넓은 자동 호출 조건, 불필요한 패키지 설치·외부 게시, 프로젝트 규칙과의 충돌을 비교한다. 인기나 설치 수만으로 선택하지 않는다.
5. 적합한 후보를 간결하게 제시한다. 후보마다 용도, 현재 작업에 도움이 되는 부분, 원본 링크와 도입 시 조정할 점을 설명한다. 적합한 후보가 없으면 검색 범위와 이유를 밝히고 기존 기능으로 진행하거나 필요한 부분만 작성할 수 있는지 판단한다.

## 도입과 기존 스킬 보완

- 사용자 지정 경로와 저장소의 스킬 작성 규칙을 우선한다. 대상 경로가 심볼릭 링크이면 실제 원본과 관리 방식을 먼저 확인한다.
- `~/.agents/skills`가 이 저장소의 `skills/`에 연결돼 있으면 저장소 원본에 반영한다. 기존 스킬과 이름이 충돌하면 사용자 변경을 보존하고 필요한 부분을 병합한다. 설치기나 일괄 업데이트로 관리 중인 스킬을 덮어쓰지 않는다.
- 참고용 통합 요청은 필요한 판단 기준을 기존 또는 새 스킬에 맞게 재작성한다. 원본의 모든 규칙·사례를 복사하거나 버전 의존적인 권고를 보편 규칙으로 만들지 않는다. 원본 링크를 남기고, 원문·코드를 재사용할 때는 라이선스와 고지 조건을 보존한다.
- 새 스킬을 만들거나 크게 수정할 때 사용 가능한 스킬 작성 지침을 적용한다. Codex의 시스템 `skill-creator`가 제공되면 사용하고, 해당 스킬을 다시 사용자 스킬 경로에 복제할 필요는 없다.
- 스킬 이름·frontmatter·상대 참조·메타데이터를 확인하고, 스크립트가 있으면 요청 범위 안에서 동작을 검증한다. 설치 명령의 성공만으로 현재 에이전트가 로드했다고 보고하지 않는다.

## 검색 도구

사용 가능한 검색 도구로 [skills.sh](https://skills.sh/)와 원본 저장소를 확인한다. Skills CLI를 사용할 환경이면 아래 명령으로 검색하거나 저장소의 후보를 나열할 수 있다. 설치된 버전의 도움말과 프로젝트의 패키지 실행 규칙을 먼저 확인한다.

```bash
# 작업에 맞는 검색어로 후보 검색
npx skills find "$QUERY"
# 특정 저장소에 제공되는 스킬 조회: 설치하지 않음
npx skills add "$SOURCE" --list
```

CLI를 사용할 수 없어도 웹과 원본 파일로 탐색할 수 있다. 검색을 위해 시스템에 CLI를 영구 설치하지 않는다. `add`의 `--list` 없는 실행, `remove`, `update`는 실제 파일을 바꾸므로 요청된 도입·정리 범위에서만 사용한다. 전역 일괄 설치·업데이트를 기본 경로로 삼지 않는다.

참고: [Vercel find-skills 원본](https://github.com/vercel-labs/skills/tree/main/skills/find-skills), [Skills CLI 사용법](https://github.com/vercel-labs/skills#readme). 탐색 흐름을 참고하고 호출 조건과 관리 경로 처리 기준을 이 저장소에 맞게 정리했다.
