# Figma 스킬 모음

Figma MCP를 사용하는 작업별 스킬이다. 각 하위 폴더의 `SKILL.md`를 독립적으로 호출한다. `figma`는 정리용 그룹이므로 별도의 `SKILL.md`를 두지 않는다. 공통 규칙이 필요하면 각 스킬에서 `use-figma`를 명시적으로 참조한다.

## 작업별 스킬


| 로컬 스킬                                                     | 용도                         | 참고한 공식 스킬                  |
| --------------------------------------------------------- | -------------------------- | -------------------------- |
